# 공통 업무 상황형 문제 개편

기준일: 2026-10-25. 이 문서는 현재 출제 정책이며, `content-analysis.md`의 15:5 혼합 정책을 대체합니다.

## 카테고리와 문항 수

- 함정사업: 함종 전용 125문항. 구축함·호위함·기뢰전함 각 21, 상륙함·잠수함 각 20, 지원·구조함 22.
- 공통 업무: 획득·소요, 계약관리, 사업관리·시험평가 각 20문항, 총 60문항.
- 공통 업무는 `/common`에서 선택합니다. 모든 회차는 선택 단원으로만 구성하며 부족분을 다른 단원에서 보충하지 않습니다.
- 기존 공통 기초 24문항은 ID와 원문을 보관한 채 `retired`로 출제에서 제외했습니다. 전체 데이터 209문항 중 현재 출제 185문항입니다.
- 구축함·호위함·기뢰전함의 기존 고유 개념이 각 19개였으므로 함정 소요기획 상황형을 하나씩 보충해 모든 단원에서 고유 개념 20개 출제를 지원합니다.

## 문항 작성 원칙

각 상황은 공개된 규정에 근거해 자체 구성했습니다. 실제 기관·업체의 비공개 사건, 성능 수치, 계약내용을 사용하지 않습니다.

1. 담당자·현재 상태·판단할 조치를 문항에 제시합니다.
2. 주요 성능 수정과 계약변경, 납품과 검사·인수, 입증과 확증, 집행과 성과, 장비 인도와 사업종결을 구분합니다.
3. 필요한 전제는 문항에 명시하고 특례·면제 여부를 확인하도록 합니다. 사유 발생만으로 자동 승인·면제되는 것으로 단정하지 않습니다.
4. 정답 해설과 2~3단계의 처리 순서를 제공합니다. 실제 처리에서는 권한, 적용 법령·특수조건과 최신 판본을 함께 확인합니다.
5. 공개 상태는 `published`입니다. 개별 전문가의 검수자·검수일을 임의로 만들지 않습니다. 전문가 검수 시 해당 문항 ID를 기준으로 `reviews.ts`에 기록합니다.

상황형은 `scenario`, `citation`, `actionSteps`와 안정적인 개념 ID를 갖습니다. 세션 검증은 이 필드의 변조도 거부합니다. 과거 혼합 진행 회차는 새 정책으로 잘못 복원하지 않으며 완료 이력은 유지합니다.

## 유지보수

규정 개정 시 `business-content.ts`의 근거 판본과 관련 문항·해설을 함께 검토합니다. 단순히 근거 확인일만 바꾸지 않습니다. 검사·납기·금액 등 분쟁으로 이어질 수 있는 문항은 실제 적용 조문과 계약 유형을 재확인합니다.
