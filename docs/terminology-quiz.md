# 방위사업 용어 퀴즈

기준일: 2026-10-25. `/common`의 마지막(업무 04) 단원은 `/setup/common-terms`로 연결됩니다. 이 추가로 현재 출제 문항은 함종 125 + 공통 상황형 60 + 용어형 120 = 305개입니다. 기존 문항과 완료 이력은 유지합니다.

## 형식과 범위

정의 또는 실제 사용 상황을 읽고 **정답 용어 1개와 혼동 용어 3개** 중에서 고릅니다. 한 용어에 한 문항을 부여해 서로 다른 용어 120개를 담았습니다. 5·10·20문항을 선택하고 무작위로 풀며, 한 회차 내 같은 개념 중복은 없습니다. 회차 간 반복을 차단하는 기능은 아닙니다.

| 작성 분야 | 용어 수 | 예시 |
| --- | ---: | --- |
| 소요·획득 기획 | 20 | 소요제기, 소요결정, 소요검토요청서, 소요제기서, 전력소요서, ROC, ORD |
| 사업·개발·함정 설계 | 20 | 제안요청서, 제안서평가, IPT, 탐색개발, 체계개발, 양산, 연동통제문서 |
| 기술·자료·공학 관리 | 20 | 목표비용관리, TRA, PDR, CDR, 형상관리, 기술변경, 표준화, 목록화 |
| 계약관리 | 20 | 계약보증금, 채권양도, 계약인수, 수정계약, 납품, 검사, 지체상금 |
| 시험평가·전력화·수명주기 | 20 | DT&E, OT&E, TEMP, 입증시험, 확증시험, 전력화평가 후속조치, LCSP |
| 운용·군수지원 | 20 | RAM, RAM-C, PSA, PSM, PBL, CLS, BII, CSP, ASL, 부품단종관리 |

사용자가 예시로 제시한 소요검토서는 「국방전력발전업무훈령」 제12조의 정식 문서명인 **소요검토요청서**를 사용합니다. 소요제기서·전력소요서와 각각 다른 문서로 묻습니다. 후속조치는 대상이 모호하지 않게 전력화평가 이후 조치로 구체화했습니다.

## 근거와 작성 원칙

기존에 확인한 국방전력발전업무훈령, 방위사업관리규정, 물품구매(제조)계약일반조건, 계약변경업무 처리지침, 획득단계 수명주기관리규정을 사용합니다. 판본은 [상황형 안내](business-scenarios.md)의 공식 근거 표를 참조하세요. 신규 근거는 국가법령정보센터의 [공개 별표 1 용어의 정의](https://www.law.go.kr/flDownload.do?bylClsCd=200201&flNm=%5B%EB%B3%84%ED%91%9C%201%5D%20%EC%9A%A9%EC%96%B4%EC%9D%98%20%EC%A0%95%EC%9D%98&flSeq=140922763)입니다. 이 별표는 개념 학습을 위한 공개 참고자료로 표시하며, 확인하지 않은 시행일이나 최신 판본이라는 설명을 붙이지 않습니다. 실제 절차·권한은 현행 규정과 해당 계약조건을 우선 확인합니다.

- 원문을 그대로 옮기지 않고 정의를 요약하거나 업무 상황으로 재구성했습니다. 실제 기출문제나 전문가 검수 완료를 주장하지 않습니다.
- 보기는 전부 용어입니다. 행동 문장·동의어·같은 용어의 다른 표기를 오답으로 넣지 않습니다. 비슷한 단계·문서·지원 개념을 비교합니다.
- 정답 용어가 질문에 그대로 포함되지 않도록 검사합니다. 약어가 포함된 보기에서는 한글 표제어를 기준으로 검사합니다.
- 해설은 정의와 유사 개념의 차이, 직접 근거 및 원문 링크를 제공합니다. 용어형에는 실제 조치를 묻는 상황형의 '업무 처리 순서'를 억지로 붙이지 않습니다.
- 각 `q-term-*` ID와 `term-*` 개념 ID는 안정적으로 유지합니다. 오답은 실제 등록된 다른 용어 ID 3개로 참조해 누락·중복을 검출합니다.
- 새 주제 `용어·개념`도 출제 순환에 포함합니다. `common-terms`는 공통 업무에 속하지만 기존 공통 상황형 60문항과 섞이지 않습니다.

단위 테스트는 용어·정답의 고유성, 전체 보기의 용어 여부, 질문의 정답 노출, 선택 수와 무작위 정답 매핑을 확인합니다. PC·모바일 브라우저 검증은 마지막 카드, 5·20문항 선택, 실제 용어 보기, 새로고침 복원, 채점·해설·근거·오답 재도전과 접근성·가로 넘침을 확인합니다. Pages 하위 경로에서 직접 진입·복원도 검증합니다.
