# 피드백 운영 안내

## 방문자와 관리자의 이용 방법

- 방문자: 사이트 메뉴의 **피드백**에서 의견을 작성하고 **피드백 보내기**를 누릅니다. 로그인·이름·연락처 입력은 필요하지 않습니다.
- 관리자: https://tally.so 에 폼을 만든 계정으로 로그인하고 **함정길잡이 피드백 → Submissions**에서 제출 내용을 확인합니다.
- 공개 양식: https://tally.so/r/X5lb1e
- 의견 내용은 공개 게시판이나 GitHub Issues에 올라가지 않습니다. Tally의 외부 서버에 보관되며 폼 계정의 관리자가 확인합니다.

## 비용

Tally Free의 기본 질문, 응답 저장, 사이트 삽입 기능만 사용합니다. 결제 수단을 등록하거나 유료 요금제를 선택할 필요가 없습니다. 파일 첨부·유료 브랜딩 제거·커스텀 도메인 등은 사용하지 않습니다. 무제한 응답 표기는 [공정 사용 정책](https://tally.so/help/fair-use-policy) 범위 내이며 미래 요금이나 서비스 지속을 보장하는 뜻은 아닙니다. 대량 이용 시 정책을 확인하고 유료 전환 대신 폼 접수를 중지하거나 다른 무료 수단을 검토합니다.

## 무엇을 저장하는가

필수 긴 글 질문 **어떤 점을 개선하면 좋을까요?**의 응답을 받습니다. 개인정보·비공개 업무자료는 적지 않도록 안내합니다. 학습 기록, 정답·점수, 브라우저 로컬 저장소의 내용은 폼에 전달하지 않습니다. Tally 서비스가 처리하는 기술 정보에는 해당 서비스 개인정보 정책이 적용됩니다.

## 실제 저장 확인

1. 사이트의 피드백 페이지에서 고유한 확인 문구를 제출합니다.
2. 폼의 제출 완료 화면이 나타나는지 확인합니다. 단순 iframe 로드·버튼 클릭을 저장 성공으로 간주하지 않습니다.
3. 관리자 **Submissions**에서 동일 문구와 제출 시각을 확인합니다. 이 단계까지 확인해야 실제 저장을 검증한 것입니다.
4. 시험 의견은 실제 이용자 의견과 구별되도록 `[연결 확인 테스트]`로 시작합니다.

자동 테스트는 외부 폼을 가짜 응답으로 대체해 연결 경로·접근성·반응형 화면을 검사하며 실제 Tally 저장을 보장하지 않습니다. 실제 저장 확인은 위 절차로 별도로 수행합니다. 진행 결과는 PR의 검증 항목에 기록합니다.

2026-10-19 확인: Pages용 로컬 빌드의 `/naval-acquisition-learning/#/feedback` 안에 삽입한 실제 폼으로 `[연결 확인 테스트]` 의견 한 건을 제출했습니다. 한국어 제출 완료 화면과 관리자 Submissions의 Completed 1건에서 `feedback-X5lb1e-20261019-01` 문구를 확인했습니다. 시험 의견은 저장 증빙으로 남겨 두었습니다.

## 설정과 장애 대응

`src/feedback-settings.json`의 `tallyFormId`는 공개 URL의 마지막 ID입니다. 비밀키가 아니며 브라우저에서 보여도 됩니다. 폼을 교체하면 이 값과 문서의 관리·공개 주소를 바꾸고 빌드·배포합니다. 계정 비밀번호나 API 토큰은 필요 없습니다.

양식이 보이지 않으면 페이지의 **새 탭에서 작성하기**를 사용합니다. 폼이 닫혀 있거나 Tally 장애로 제출이 실패하면 저장됐다고 안내하지 말고 관리자 화면을 확인합니다. 장기 중단 시 ID를 비워 접수 준비 중 화면으로 전환한 뒤 재배포합니다. 운영자 계정에서 응답 공개·공유 링크를 켜지 않습니다.
